# BlueX Hub v1.0

[Script Luau completo](BlueX_Hub_v1.0.txt) · [Documentação](BlueX_Hub_v1.0_LEIA-ME.md) · [Validação](BlueX_Hub_v1.0_VALIDACAO.txt)

O arquivo principal é autocontido, com interface mobile, quatro abas, ESP visual, controladores condicionados a permissões, diagnóstico e preferências na sessão.

**Não é plug-and-play no MM2 publicado.** Foi escrito como LocalScript para uma experiência editável no Roblox Studio. Dados e automações de jogo exigem o contrato opcional autorizado descrito no cabeçalho. A publicação no GitHub não confirma compatibilidade com Delta ou outros executores.

Verificação realizada: compilação com Luau oficial 0.745 e 77 testes lógicos aprovados com doubles de serviços. Sem execução no Roblox Studio, MM2 ou Android; física, toque, coleta, reset e combate permanecem sem validação real. Não há persistência entre sessões.

Os comandos de reprodução na documentação referem-se ao workspace original de desenvolvimento; esta pasta publica os entregáveis finais.
