# SKYNETchat — captura estática

Esta pasta registra a captura estática recebida de SKYNETchat.

## Limitações conhecidas
O ZIP fornecido contém o HTML e parte dos estilos/imagens, mas não contém os módulos JavaScript compilados do SvelteKit nem os serviços de backend. Portanto, esta captura não implementa login, conversas, geração de imagens ou envio de mensagens. Não é o código-fonte completo do serviço.

Para acessar o serviço original, visite https://skynetchat.net/.

A captura foi colocada nesta pasta em uma branch separada para não alterar os arquivos existentes do repositório.
