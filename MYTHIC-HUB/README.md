# MYTHIC HUB

Projeto de personalizacao do hub para Murder Mystery 2.

## Identidade visual
- Fundo: preto `#09070D`
- Barra lateral: roxo-escuro `#140B20`
- Paineis: roxo `#1B1028`
- Destaques: vermelho `#E52B50`
- Brilho do logo: roxo `#9743EF`

## Chat MYTHIC
A aba **MYTHIC CHAT** foi preparada exclusivamente para usuarios do hub.
**Importante:** a copia fornecida possui bloqueio de rede e nao inclui um servidor de chat. Sem autenticacao e moderacao no backend, o chat nao pode ser considerado exclusivo nem funcional. A interface informa esse estado e nao publica mensagens no chat geral do Roblox.
